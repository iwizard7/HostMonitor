# 🍎 Host Monitor для macOS

Стильное, быстрое и современное профессиональное приложение для мониторинга доступности сетевых хостов, серверов и IP-адресов под macOS.

Оформлено в нативной эстетике **macOS Glassmorphism** (акцентные цвета, эффект матового стекла, неоновые индикаторы доступности, системный трей) и предоставляет исчерпывающую информацию о качестве соединения.

---

## ✨ Возможности

- 🚀 **Мультипротокольный мониторинг**:
  - **ICMP Ping**: традиционный пинг по IP или домену (до долей миллисекунды).
  - **TCP Port Ping**: проверка доступности конкретных сервисов (SSH `22`, PostgreSQL `5432`, MySQL `3306`, VPN `51820` и др.).
  - **HTTP/HTTPS статус**: мониторинг доступности веб-сайтов и API с замером задержки ответа сервера.
- ⚡ **График пинга в реальном времени**:
  - Плавный график задержки (ms) на базе Chart.js с поддержкой **выбора временного диапазона**: `[1м] [5м] [15м] [1ч] [24ч] [Всё]`.
- 📊 **Комплексная аналитика качества связи**:
  - **Текущий пинг** и **TTL**.
  - **Джиттер (Jitter, мс)**: замер колебания задержки пакетов в реальном времени.
  - **Рейтинг качества соединения (Quality Score)**: автоматическая оценка стабильности канала (`A+`, `A`, `B`, `C`, `F`).
  - **Процент доступности (Uptime %)** с динамическим статус-баром.
  - **Потеря пакетов**: точный подсчет числа потерянных пакетов за всю историю с предупреждающей подсветкой.
  - **Мин / Сред / Макс** пинг за историю наблюдений.
- 🏷️ **Группировка и фильтрация хостов**:
  - Разделение хостов по категориям (например, `Роутеры`, `DNS`, `Серверы`, `Рабочие VPN`).
  - Фильтрация в 1 клик с помощью табов в боковой панели.
- 🔔 **Алерты и Уведомления**:
  - **Нативные системные уведомления macOS** при падении или восстановлении хоста.
  - **Звуковые оповещения (Audio Chime)** при смене статуса.
  - Переключатель `Алерты: Вкл / Выкл` прямо в заголовке окна.
- 🍏 **Интеграция в macOS Menu Bar (Строка меню)**:
  - Компактный индикатор в строке меню рядом с часами (`🟢 42.5ms` или `🔴 1 DOWN`).
  - Быстрый просмотр статуса всех хостов прямо из выпадающего меню трея.
- 🗺️ **Интерактивная трассировка маршрута (Traceroute)**:
  - Наглядная визуализация цепочки узлов (Hop Route Visualizer).
  - **Умное распознавание топологии**: определяет локальный роутер/шлюз (`192.168.1.1`), виртуальные туннели (`VPN / Proxy`, например Shadowrocket `utun4`) и внешние магистральные узлы.
- 💾 **Экспорт статистики в CSV**:
  - Выгрузка подробной истории по текущему активному хосту в один клик.
  - Поля: дата/время (ISO 8601), имя хоста, цель, группа, протокол, статус (`ONLINE` / `OFFLINE`), задержка (мс), TTL и текст ошибок.
- 🗄️ **Автономное сохранение**: база данных SQLite хранит все хосты, группы, типы проверок и историю пингов между перезапусками.

## 🛠️ Стек технологий

- **Бэкенд**: Python 3, FastAPI, Uvicorn, AsyncIO (ICMP Ping / TCP Socket / HTTP SSL), AioSQLite, Rumps (macOS Menu Bar).
- **Фронтенд**: HTML5, Vanilla CSS3 (macOS Design System, Glassmorphism, Dark Mode), JavaScript ES6, Chart.js, Web Audio API, Web Notifications API.
- **База данных**: SQLite (`data/monitor.db`).

## 🚀 Быстрый запуск

### 1. Требования
- macOS (Apple Silicon M1/M2/M3/M4 или Intel).
- Python 3.9 или новее.

### 2. Запуск в 1 клик через терминал

В папке проекта выполните:
```bash
./run.sh
```
Скрипт автоматически:
1. Создаст виртуальное окружение `venv` (если его нет).
2. Установит необходимые зависимости из `requirements.txt`.
3. Запустит локальный сервер мониторинга на порту `8000`.
4. Запустит индикатор в **строке меню macOS (Menu Bar)**.
5. Автоматически откроет окно приложения в браузере (`http://localhost:8000`).

## 📖 Как пользоваться

### Добавление нового хоста
1. Нажмите кнопку **«+ Добавить хост»** в верхнем правом углу.
2. Введите имя (например, `Рабочий VPN` или `Веб-сайт`).
3. Укажите IP-адрес или домен.
4. Выберите протокол:
   - **ICMP Ping**: для проверки доступности хоста в сети.
   - **TCP Порт**: для проверки конкретного порта (22, 443, 3306 и т.д.).
   - **HTTP/HTTPS Запрос**: для веб-ресурсов.
5. Укажите группу (например, `Серверы`) и интервал проверки (1.0с, 2.0с и т.д.).
6. Нажмите **«Добавить и запустить»**.

### Выбор временного диапазона графика
Над графиком пинга переключайте кнопки:
- **`1м`**: детальный живой график за последнюю минуту.
- **`5м` / `15м` / `1ч` / `24ч`**: обзор тренда задержки и всплесков за выбранный период.
- **`Всё`**: полная история наблюдений.

### Фильтрация по группам
В левой панели над списком хостов используйте плашки (`Все`, `Основное`, `Серверы` и т.д.) для быстрой фильтрации.

### Трассировка маршрута (Traceroute)
Нажмите кнопку **«Трассировка»** в карточке хоста — приложение построит цепочку:
`[Ваш Mac] ➔ [Локальный роутер (192.168.1.1)] ➔ [VPN/Proxy туннель] ➔ [Цель]`.

### Экспорт в CSV
Выберите хост и нажмите **«Выгрузить в CSV»** в карточке хоста или верхней панели. Файл скачается мгновенно.
