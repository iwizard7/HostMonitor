# 🍎 Host Monitor для macOS

Стильное, быстрое и современное приложение для мониторинга доступности сетевых хостов и IP-адресов в интернете или локальной сети под macOS.

Приложение оформлено в эстетике **macOS Glassmorphism** (акцентные цвета, эффект матового стекла, неоновые индикаторы доступности) и предоставляет исчерпывающую информацию о качестве соединения.

---

## ✨ Возможности

- 🚀 **Мониторинг любых хостов**: добавляйте хосты по IP-адресу (например, `1.1.1.1`, `8.8.8.8`, `192.168.1.1`) или доменному имени (`google.com`, `github.com`).
- ⚡ **График пинга в реальном времени**: плавный график задержки (миллисекунды, ms) на базе Chart.js с отображением последних 60 измерений.
- 📊 **Комплексная статистика доступности**:
  - **Текущий пинг** и **TTL**.
  - **Процент доступности (Uptime %)** с динамическим статус-баром.
  - **Потеря пакетов (Packet Loss %)** и подсчет успешных/неудачных запросов.
  - **Минимальный, средний и максимальный пинг** (Min / Avg / Max RTT).
- 🗺️ **Интерактивная трассировка маршрута (Traceroute)**:
  - Наглядная цепочка сетевых узлов (Hop Route Visualizer) от вашего Mac к цели.
  - **Умное распознавание топологии**: определяет локальный роутер/шлюз (`192.168.1.1`), зашифрованные туннели (`VPN / Proxy`, например Shadowrocket `utun`), промежуточные узлы провайдера и конечный хост с замером времени отклика каждого шага.
- 💾 **Экспорт статистики в CSV**:
  - Выгрузка полной истории по конкретному выбранному хосту в один клик.
  - Формат включает дату/время (ISO 8601), название, целевой хост, статус (`ONLINE` / `OFFLINE`), задержку в миллисекундах, TTL и текст ошибок при сбоях.
- ⏱️ **Гибкие интервалы проверки**: настраиваемый интервал (от 1 секунды до 10 секунд).
- ⏸️ **Управление мониторингом**: мгновенная пауза, возобновление и удаление хостов.
- 🗄️ **Автономное сохранение**: база данных SQLite хранит все хосты и историю пингов между перезапусками приложения.

---

## 🛠️ Стек технологий

- **Бэкенд**: Python 3, FastAPI, Uvicorn, AsyncIO ICMP Ping, AioSQLite.
- **Фронтенд**: HTML5, Vanilla CSS3 (macOS Design System, Glassmorphism, Dark Mode), JavaScript ES6, Chart.js.
- **База данных**: SQLite (`data/monitor.db`).

## 🚀 Быстрый запуск

### 1. Требования
- macOS (Apple Silicon M1/M2/M3/M4 или Intel).
- Python 3.9 или новее.

### 2. Запуск в 1 клик через терминал

В папке проекта выполните:
```bash
./run.sh
```
Скрипт автоматически:
1. Создаст виртуальное окружение `venv` (если его нет).
2. Установит необходимые зависимости из `requirements.txt`.
3. Запустит локальный сервер мониторинга на порту `8000`.
4. Автоматически откроет окно приложения в вашем браузере (`http://localhost:8000`).

## 📖 Как пользоваться

### Добавление нового хоста
1. Нажмите кнопку **«+ Добавить хост»** в верхнем правом углу.
2. Введите понятное имя (например, `Шлюз роутера` или `Сервер БД`).
3. Укажите IP-адрес или домен.
4. Выберите желаемый интервал проверки (1.0 сек, 2.0 сек и т.д.).
5. Нажмите **«Добавить и запустить»**. Мониторинг начнется моментально.

### Просмотр статистики и графика
- Нажмите на любой хост в левой панели (сайдбаре).
- В центре отобразится карточка хоста, статусное кольцо (**ONLINE / OFFLINE / ПАУЗА**), график изменения пинга во времени и детальная таблица последних замеров.

### Трассировка маршрута (Traceroute)
1. Нажмите кнопку **«Трассировка»** в карточке активного хоста.
2. Откроется интерактивная цепочка сетевых узлов:
   - **Ваш Mac** (`localhost`)
   - **Локальный роутер / Шлюз** (`192.168.1.1`) с реальным пингом локальной сети (~1 мс).
   - **VPN / Proxy туннель** (если включен туннель вроде Shadowrocket/WireGuard, приложение подсветит его плашкой `🔒 VPN ТУННЕЛЬ`).
   - **Промежуточные узлы и целевой сервер** с замером времени отклика каждого хопа.
3. Доступна детальная таблица шагов и кнопка **«Повторить замер»**.

### Экспорт в CSV
- **Выгрузка по активному хосту**: выберите любой хост в левой панели и нажмите кнопку **«Выгрузить в CSV»** (в карточке хоста или в верхней панели). Скачается CSV-файл со статистикой **исключительно по выбранному хосту** с именем вида `host_monitor_<ИмяХоста>_ГГГГММДД_ЧЧММСС.csv`.
- Переключитесь на другой хост — кнопка сразу переключится на выгрузку данных нового активного хоста.

#### Пример структуры CSV файла:
```csv

2026-09-17T04:02:31.298207+00:00,Cloudflare DNS,1.1.1.1,ONLINE,41.36,54,
2026-09-17T04:02:32.855606+00:00,Cloudflare DNS,1.1.1.1,ONLINE,41.78,54,
2026-09-17T04:02:34.411398+00:00,Cloudflare DNS,1.1.1.1,ONLINE,41.32,54,
```
